# Publishing QA checklist

Coway's operational checklist, organised so it can be worked through in one pass. The gate is defect-based: **PASS only when CRITICAL = 0 and MAJOR = 0.**

## Accuracy and research

- [ ] Every spec (CADR, coverage, noise, filter life, dimensions) verifiable against Coway product documentation
- [ ] Every strong claim supported by a study, certification or test report
- [ ] Every statistic carries a verifiable reference or link
- [ ] No unverified or misleading information
- [ ] No fear-inducing depiction of illness
- [ ] Product never positioned as medical - no implication of prevention, treatment or cure
- [ ] Market-specific accuracy: no US-only references in UK, DE, NL or FR content

## Terminology and compliance

- [ ] No True HEPA, GreenHEPA, H13, H14 or HEPA classification
- [ ] No HEPA vs HEPA-type comparison
- [ ] No "medical grade"
- [ ] No "cheap"; no "extremely premium"
- [ ] Wirecutter named as NYT Wirecutter, not "New York Times"
- [ ] 99.999% / 0.01 µm attributed to HyperCaptive Filtration, not to HEPA
- [ ] No named pathogen - particle size only
- [ ] Certifications claim only what they certify
- [ ] Model names and numbers exactly match the Coway catalogue
- [ ] Trademarks carried correctly: HyperCaptive™, HyperVortex™

## Localisation and units

- [ ] Correct locale declared and applied throughout (en-GB, de-DE, nl-NL or fr-FR)
- [ ] Formality rule correct and never mixed within one asset
- [ ] Sentence case headings; German noun capitalisation preserved
- [ ] UK: British spelling; metric primary with imperial in support only for room size
- [ ] DE, NL, FR: metric only; decimal comma; PM2,5
- [ ] Locale-correct dates, thousand separators, quotation marks, punctuation spacing
- [ ] Currency correct: £ for UK, € for DE, NL, FR - with locale-correct placement
- [ ] Units consistent throughout; no random mixing of m² and sq ft

## Structure and readability

- [ ] One H1 per page; clean H1 → H2 → H3 hierarchy, visually distinct
- [ ] Paragraphs in clear logical blocks - no walls of text
- [ ] Bullets, lists or tables where they aid clarity
- [ ] Sentences 15-25 words; paragraphs 2-4 sentences
- [ ] Every sentence carries specific information - zero filler paragraphs
- [ ] No section repeating a point already made elsewhere
- [ ] Internal links to relevant Coway products and related posts
- [ ] External links to credible sources wherever a claim needs one

## On-page SEO

- [ ] Meta title 50-60 characters, main keyword as an unbroken phrase, not truncated
- [ ] Meta description 140-160 characters, main keyword plus one variant, includes a CTA, complete sentence
- [ ] URL slug lowercase, hyphenated, contains the keyword
- [ ] H1 contains the main keyword naturally
- [ ] Main keyword appears at least once in the body as the exact full phrase
- [ ] Keywords integrated naturally - no stuffing, no forced exact-match strings
- [ ] Keyword set contains no named conditions (no "asthma", no "allergy sufferers")
- [ ] Local keywords labelled validated or candidate; search volume never invented

Naturalness outranks exact match. If a keyword conflicts with native grammar or brand tone, flag the trade-off rather than damaging the copy.

## Authority and sourcing

- [ ] Content reflects real user scenarios - room sizes, noise concerns, pets, flats
- [ ] References section present wherever performance claims appear
- [ ] Each claim traceable to an approved source: test lab, certification body, government or official data

## Anti-AI footprint

Lexical tics, delete on sight:

- "In today's world" / "In today's fast-paced world"
- "Let's explore" / "Let's dive in" / "Let's break it down"
- "When it comes to..."
- "Here's something most people don't realise"
- "But that's just the beginning" / "The worst part?" / "The magic happens..."
- "Wrong." / "Think again." / any one-word dramatic paragraph
- "It's not just X - it's Y"
- "The truth is..." / "Here's the thing"
- Filler adverbs: truly, certainly, completely, especially, incredibly, astonishing
- Hype: game-changer, revolutionary, unlock, supercharge, elevate, ultimate, must-have
- Fear metaphors: silent killer, the real culprit, invisible guardian

Structural tics, harder to spot and more damaging:

- [ ] No rhetorical question opening every section
- [ ] No tease-then-reveal section pattern
- [ ] No repeated "This means... This ensures... This helps..." sentence chains
- [ ] No three-item lists imposed where there are not three real items
- [ ] No paragraph restating the previous one with new adjectives
- [ ] No section closing with a forward reference to the next
- [ ] Transitions natural rather than formulaic
- [ ] Generic air purifier filler replaced by something specific to the Coway model
- [ ] Tone matches the Coway brand voice, not a generic assistant voice

The replacement for a device is not another device. State the point once, clearly, and move on.

## Images and visuals

- [ ] All images proofread for text errors and typos
- [ ] AI-generated images checked for broken text and misaligned graphics
- [ ] **AI-generated images watermarked or labelled** to meet EU transparency requirements
- [ ] Visuals consistent with Coway branding
- [ ] Alt text present and descriptive on every image
- [ ] Alt text contains no health or disease claims - the claim rules apply here too
- [ ] File names descriptive and lowercase: `coway-airmega-living-room.jpg`
- [ ] Thumbnail sized 1280 × 853
- [ ] No before/after imagery, no patient or doctor depictions

## Formatting and UI

- [ ] Buttons, CTAs and interactive elements match the Coway style guide
- [ ] Font sizes, colours and spacing consistent across the asset
- [ ] CTA placement logical - after key benefits, after comparisons, at the conclusion
- [ ] CTA copy audited for claims, same as body copy
- [ ] No emoji clusters, no Unicode pseudo-bold, no all-caps emphasis
