## Bài học (tự học)
- Khi duyệt brief collection TMF, đối chiếu meta với giới hạn riêng của skill shopify-collection-seo-tmf (description dưới 155 ký tự), giới hạn này chặt hơn khoảng 140 đến 160 của SEO-OPS.
- Khi duyệt báo cáo tháng, ngoài việc đối chiếu từng số, so các bảng top của báo cáo với đủ dòng trong tóm tắt để bắt chỗ bỏ dòng có chọn lọc (bỏ đúng những số đi ngược nhận định chính).
- Khi chạy lại một run đã có file review cũ, kiểm giờ ghi của file review và report trước; nếu review cũ hơn report thì ghi bản review mới có hậu tố _v2, nói rõ trong file mới rằng bản cũ đã lỗi thời, và không ghi đè bản cũ.
