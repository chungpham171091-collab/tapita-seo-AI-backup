# Job types this project can run (written by the Projects page)

keyword_plan (Keyword plan): Seed keywords, Ahrefs, grouping, mapping one main keyword per URL, content cluster and a draft priority plan. Fields: scope, topic*, max_pages, months
collection (Collection page): Long-form content for one collection page. Fields: collection_url, main_keyword, secondary_keywords, topic*, notes
blog (Blog post): One blog article from keyword to published post. Fields: main_keyword, secondary_keywords, topic_text, topic*, notes
product (Product batch): Meta and content for a batch of product pages. Fields: products, topic*
refresh (Page refresh): Find a page that is losing clicks and refresh it. Fields: max_pages, topic*, notes
links (Competing pages and links): Pages competing for the same main keyword, missing internal links, and proposed fixes. Fields: topic*, max_groups
offpage (Off-page round): Backlink profile, link gaps against the competitors, targets, PR angles and outreach drafts. Fields: topic*
report (Monthly report): The month's report from GSC, GA4, rank and AI citations, with every number checked. Fields: topic*
technical (Technical audit (Tapita tool)): The technical audit is done with Tapita's own tool. This job keeps the report as proof. Fields: topic*, notes
geo_prompts (GEO: prompt set): The list of prompts to track in AI engines, built from the keyword mapping and the client profile. Fields: topic*, count
geo_round (GEO: monthly round): From the month's AI citation checks: audit the pages, propose answer-first fixes, QA, publish. Fields: topic*
geo_sources (GEO: sources AI cites): Which sources and competitors AI engines cite where the client is absent, and how to get mentioned. Fields: topic*
