Thư mục dữ liệu `backlinks` (Ahrefs Site Explorer). Làm mới hằng quý hoặc trước mỗi đợt off-page.

- `ahrefs_backlinks_YYYY-MM.csv`: export Backlinks của site khách (referring page, referring domain, DR, target URL, anchor, nofollow, first seen, lost nếu có).
- `link_intersect_YYYY-MM.csv`: export Link Intersect, khách so với các đối thủ trong mục Đối thủ chính của PROJECT.md (chỉ giữ domain chưa link tới khách).

Không sửa file export gốc.
